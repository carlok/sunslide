# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch (`main`).

| Version | Supported |
|---------|-----------|
| Latest on `main` | Yes |
| Older | No |

## Reporting a vulnerability

**Do not open a public GitHub issue** for security vulnerabilities.

Report them through GitHub **private vulnerability reporting**:

https://github.com/carlok/sunslide/security/advisories/new

Include a clear description, steps to reproduce, and impact if you can. If the issue is in a dependency (for example three.js), mention the version and whether you believe the flaw is in this repo’s use of it.

## What to expect

- We acknowledge receipt when we can and review reports in a reasonable timeframe.
- We may ask for clarification or a minimal reproducer.
- We coordinate disclosure after a fix is available, when practical.
- We do not guarantee a specific response time; severity and complexity affect timing.

General questions and non-security bugs belong in [issues](https://github.com/carlok/sunslide/issues) using the templates.

Maintainer: [@carlok](https://github.com/carlok) on GitHub.
